# Yard Planner

Yard Planner is a gardening and lawn management tool that provides zone-based recommendations, seed details, and weed control information.

## Live Demo
[Yard Planner](https://drewbrownie21.github.io/yard-planner/)

---

## Features

- **Hardiness Calculator**: Enter a zip code to determine USDA Hardiness Zone.  
- **Grass Recommendations**: Suggested grass types for the user’s region.  
- **Grass Care**: Maintenance tips for healthy grass.  
- **Produce**: Information on region-appropriate fruits and vegetables.  
- **Seeds**: Dropdown selection displaying germination time, harvest days, planting depth, temperature, and sunlight needs.  
- **Weeds**: Dropdown selection with chemical control options, best control timing, growth habits, and sunlight requirements.  
- **UI Tools**: Dark mode toggle, reset, and edit controls.
